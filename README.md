# Vue.Arshia - Premium Vue.js Dashboard

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Vue.js](https://img.shields.io/badge/vue.js-3.x-green.svg)
![Tailwind CSS](https://img.shields.io/badge/tailwindcss-3.x-38bdf8.svg)

A modern, high-performance dashboard template built with Vue 3, Vite, and Tailwind CSS. Featuring a glassmorphism UI design, interactive charts, and a fully responsive layout.

## 🚀 Features

- **Glassmorphism UI**: Beautiful translucent components with rich gradients.
- **Interactive Charts**: Powered by ApexCharts for dynamic data visualization.
- **Responsive Design**: Mobile-first approach ensuring perfect rendering on all devices.
- **Authentication Flow**: Login page with navigation guards (Mock implementation).
- **Toast Notifications**: Global feedback system for user interactions.
- **Data Tables**: client-side search, pagination, and skeleton loading.
- **Interactive Calendar**: Event management interface.
- **Kanban Board**: Project management view.

## 🛠️ Tech Stack

- **Framework**: [Vue.js 3](https://vuejs.org/) (Composition API)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: [Pinia](https://pinia.vuejs.org/)
- **Routing**: [Vue Router](https://router.vuejs.org/)
- **Charts**: [Vue3-ApexCharts](https://apexcharts.com/)
- **Icons**: [Heroicons](https://heroicons.com/)

## 📦 Installation

1.  **Clone the repository**

    ```bash
    git clone https://github.com/Arshiamk/Vue.js.git
    cd Vue.js/vue-dashboard
    ```

2.  **Install dependencies**

    ```bash
    npm install
    ```

3.  **Start development server**

    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
